# Plan B

**A simple, private-by-default body recomposition tracker.**

Plan B is a dependency-free, mobile-first training log for the goal of building muscle, improving proportions, and developing a sustainable routine. It begins with three full-body workouts per week, using bodyweight and a single 20 lb dumbbell.

## Open the app

After enabling GitHub Pages for this repository:

1. In the repo, choose **Settings → Pages**.
2. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
3. Choose **main** and **/(root)**, then save.
4. Visit `https://bartelbyscribbler.github.io/Plan-B/`.

There is no build step and no dependencies. **Use the GitHub Pages URL rather than opening the HTML file directly** for reliable browser storage and offline behavior. In Chrome on Android, you can use the browser menu's **Add to Home screen** option. After your first online visit, the app also caches its interface for offline use.

## Features

- Record each strength set, including weight, reps, and notes.
- Save a workout draft while you train and finish when ready.
- Log weight, waist, chest, arm measurements, sleep, and energy.
- See workouts per week and measurement trends.
- Track simple daily habits: protein, walking, and sleep.
- Review history and export/import JSON backups.
- Use it on a narrow mobile screen.

## Privacy and backups

**Important:** This repository is public, but your personal entries do **not** get committed to GitHub. Everything is saved in your current browser's `localStorage`. Different devices and browsers **do not automatically sync**. Private or incognito windows, clearing browser storage, or uninstalling some browser apps can erase entries. Use **Data → Export backup** regularly. Imported backups replace your local records, after confirmation.

No external analytics, accounts, database, or network calls are required.

## Starter training routine

Three nonconsecutive days weekly (for example, Mon/Wed/Fri). Start with 2 sets per movement, increasing to 3 as tolerated. Leave 2–3 repetitions in reserve instead of grinding to failure.

| Exercise | Reps | Starting resistance |
| --- | --- | --- |
| Push-up or incline push-up | 6–12 | Bodyweight |
| One-arm dumbbell row | 10–15 / side | 20 lb if controllable |
| Split squat | 8–12 / side | Bodyweight |
| Single-leg Romanian deadlift | 8–12 / side | Bodyweight or 20 lb |
| One-arm overhead press | 8–12 / side | Use lighter resistance if needed |
| Dumbbell curl | 10–15 / side | Use lighter resistance if needed |

Numbers are starting ranges, not mandatory targets. Modify or stop any movement causing pain. Support yourself securely when rowing, especially with a taller frame.

## Product notes

- Weight entries are in pounds; circumferences are in inches.
- Unilateral movements should be logged as reps **per side**.
- When an exercise is logged with weight 0, this means bodyweight or unweighted, not that the exercise had no resistance.
- This is a training journal, not a medical assessment.
